## A. 공통 브리프 (모든 화면 요청 앞에 붙임)

```
프로젝트: AI4CEO 졸업생 포털 — AI 코딩 교육을 수료한 CEO 약 500명(1~17기)이
카카오톡 단톡방과 구글 드라이브 대신 쓰는 모바일 우선 웹앱(PWA).
핵심 가치: "새 자료는 여기 있다" — 자료를 빨리 찾고, 새 자료·공지를 놓치지 않는다.
사용자: 40~60대 CEO(바쁘고 스마트폰 위주, 비밀번호를 싫어함) / 교수·운영진(업로드·공지·명단 관리).

톤 & 스타일: 다크 모드 전용, 절제되고 전문적인 느낌. 장식 최소, 정보 밀도는 높되 여백은 넉넉하게.
색: 배경 #0f0f0f, 카드 #1a1a2e, 입력창 #111827, 경계선 #1f2937,
    포인트 인디고 #6366f1(hover #4f46e5), 텍스트 #f9fafb / #9ca3af.
    상태색 성공 #4ade80, 경고 #fbbf24, 오류 #f87171, 정보 #60a5fa.
폰트: Pretendard(한글) + Inter(영문·숫자). 아이콘: Lucide. 모서리 12px, 간격 4px 그리드.
기수 배지: 1~3기 초록, 4~6기 파랑, 7~9기 보라, 10~12기 빨강, 13~15기 노랑, 16기~ 인디고(배경은 어두운 틴트 + 밝은 글자).
카피: 정중한 존댓말(~합니다/~하세요), 이모지 사용 안 함.

레이아웃: Mobile(<640px) 하단 탭바 5개(홈·자료·공지·멤버·나) + 1열 /
          Tablet 2열 / Desktop(>1024px) 좌측 고정 사이드바 240px + 본문.
접근성: 모바일 본문 16px 이상, 터치 영역 44px 이상, 본문 대비 4.5:1 이상,
        핵심 정보에 #6b7280(muted) 사용 금지(placeholder 전용).
모든 화면에 Mobile(390px)과 Desktop(1280px)을 함께, 빈 상태·로딩(스켈레톤)·오류 상태 포함.
```

## E. 화면별 프롬프트 (붙여넣기용 예시)

```
[공통 브리프 A를 먼저 붙여넣기]

지금 요청: N1 로그인 / 가입 화면을 디자인해줘.
- 비밀번호 없이 이메일로 받은 6자리 코드로 로그인. 중앙 카드에 이메일 입력 + "인증 코드 보내기".

  (2) 명단에 없는 이메일 → "승인 대기" 안내 + 이름·기수·회사 신청 폼 (3) 코드 오류/만료.
```

## F. 요청 순서 (권장)

1. N1 로그인 → N2 홈 → 자료 라이브러리(조정) → N3 공지 (S1~S3 Do에 필요)
2. 멤버 디렉토리·프로필(조정) + N4 설정 (S4)
3. N5~N9 관리자 5종 (S2~S5에서 단계적으로 필요, 자료 업로드 N8을 가장 먼저)
4. N10 PWA 자산, 랜딩 조정 (S5~S6)

> 이 순서는 Plan의 제안 스프린트 순서(S1 Auth → S2 Library → S3 Migration & Notice → S4 Notify & Directory → S5 Admin & PWA → S6 Deploy)에 맞춘 것이다. 관리자 업로드(N8)는 S2에서 이미 필요하므로 앞당긴다.
