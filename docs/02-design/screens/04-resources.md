## 화면 목적
강의 자료를 기수/카테고리별로 탐색하고 다운로드 — 구글 드라이브 대체

## 레이아웃

### Desktop
```
[검색바 (전체폭)]
[필터 바: 기수 드롭다운 | 카테고리 탭 | 정렬]
[자료 목록: ResourceItem 리스트 or 그리드 토글]
```

### 자료 상세 (슬라이드 패널 or 모달)
```
[파일 아이콘 or PDF 미리보기]
[제목 / 기수배지 / 날짜 / 다운로드수]
[설명]
[다운로드 버튼]
[관련 자료 추천]
```

### Mobile
```
[검색바]
[기수 선택 (가로 스크롤 칩)]
[카테고리 탭]
[ResourceItem 카드 목록]
```

## UI 컴포넌트
- `SearchBar` — 실시간 검색 (debounce 300ms)
- `FilterBar` — 기수 Select + 카테고리 Tabs + 정렬 Select
- `ResourceItem` — 파일아이콘·제목·기수배지·날짜·다운로드수·즐겨찾기
- `FileTypeIcon` — PDF/VIDEO/CODE/IMAGE 타입별 아이콘+색상
- `PDFViewer` — 인라인 PDF 렌더링
- `VideoEmbed` — YouTube/Vimeo 임베드
- `CodeViewer` — syntax highlight + 복사 버튼

## 카테고리 탭
`전체` · `강의자료` · `코드` · `영상` · `참고자료` · `과제`

## 상태 변형
- 검색 결과 없음: "검색 결과가 없습니다" + 검색어 초기화
- 로딩: ResourceItem 스켈레톤
- 파일 다운로드 중: 진행률 표시

## 인터랙션 노트
- 검색어 입력 시 실시간 하이라이팅
- 즐겨찾기 하트 토글 → 즉각 반영
- 파일 클릭 → 상세 슬라이드 패널

## Handoff 체크리스트
- [ ] 목록 화면 (리스트/그리드 뷰)
- [ ] 필터 + 검색
- [ ] 자료 상세 패널
- [ ] PDF/영상/코드 뷰어 각각
