# Screen: 기수 디렉토리

| 항목 | 값 |
|------|----|
| **연결 기능** | F5. 기수 관리 |
| **연결 Sprint** | Sprint 1 |
| **PDCA 단계** | Design → Do |
| **상태** | ⬜ 디자인 대기 |

---

## 화면 목적
기수별 정보 탐색 + 멤버 디렉토리 + 기수 간 네트워킹

## 레이아웃

### 기수 목록
```
[현재 기수 (17기) 카드 — 대형 히어로]
[이전 기수 그리드: 1~16기 카드]
```

### 기수 상세
```
[기수 헤더: 번호·기간·멤버수·CohortBadge(대형)]
[탭: 멤버 | 프로젝트 | 임팩트 스토리]
─── 멤버 탭 ───
[멤버 카드 그리드: 아바타·이름·회사·직책]
─── 프로젝트 탭 ───
[ProjectCard 목록 (해당 기수만)]
─── 임팩트 탭 ───
[ImpactCard 목록 (해당 기수만)]
```

## UI 컴포넌트
- `CohortHeroCard` — 현재 기수 강조 카드 (진행 중 배지)
- `CohortCard` — 기수번호·기간·멤버수·대표 아바타 5개
- `MemberCard` — 아바타·이름·회사·직책·프로필 링크
- `CohortProgressBar` — 10주 중 현재 주차 진도 (재학생만)

## 상태 변형
- 현재 기수: "진행 중" 그린 배지
- 졸업 기수: 졸업 날짜 표시
- 멤버 카드: 본인이면 "나" 배지

## Handoff 체크리스트
- [ ] 기수 목록 (현재 + 이전)
- [ ] 기수 상세 3탭
- [ ] 멤버 카드 그리드
