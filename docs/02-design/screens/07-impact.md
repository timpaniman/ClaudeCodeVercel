## 화면 목적
CEO들의 AI 도입 실제 성과를 수치 중심으로 전시 — 신규 수강생 동기부여

## 레이아웃

### 목록 (Desktop)
```
[필터 바: 업종 탭 | 기수 필터 | 정렬]
[히어로 임팩트 카드 (대형, 상단 1개 Featured)]
[ImpactCard 3열 그리드]
```

### 목록 (Mobile)
```
[업종 가로 스크롤 탭]
[Featured 카드 (전체폭)]
[ImpactCard 1열 목록]
```

### 스토리 상세
```
[임팩트 수치 헤더 (큰 숫자 + 단위 + 설명)]
[작성자: 아바타·이름·회사·직책·CohortBadge]
[배경 섹션: AI 도입 전 문제]
[적용 AI 기술: 태그 목록]
[결과 섹션: 구체적 수치 + 설명]
[Claude 자동 생성 태그]
[좋아요 + 공유 버튼]
```

### 스토리 등록 폼
```
[업종 선택]
[적용 AI 기술 (멀티 선택)]
[임팩트 수치 입력: 숫자 + 단위 선택 (시간/%, 원, 건수)]
[배경 설명 (textarea)]
[결과 설명 (textarea)]
[제출 → Claude 자동 태그 생성 후 미리보기]
```

## UI 컴포넌트
- `ImpactCard` — **수치 매우 크게(2.5rem)** + 단위 + 업종배지 + 작성자
- `FeaturedImpactCard` — 대형 히어로 카드 (배경 그라디언트)
- `IndustryBadge` — 업종별 색상 배지 (금융·제조·유통·의료·IT 등)
- `ImpactNumber` — 수치 강조 컴포넌트 (카운트업 애니메이션)
- `TechTagList` — 적용 AI 기술 태그
- `UnitSelector` — 시간/비율/금액/건수 단위 선택

## 업종 탭
`전체` · `금융` · `제조` · `유통/이커머스` · `의료` · `IT/SaaS` · `기타`

## 상태 변형
- 빈 상태: "첫 임팩트 스토리를 등록해보세요" + CTA
- Claude 태그 생성 중: 로딩 스피너
- 등록 완료: "스토리가 등록됐습니다" 토스트

## 인터랙션 노트
- ImpactCard 진입 시 수치 카운트업 애니메이션
- Featured 카드 주기적 순환 (3초)
- 수치 입력 시 카드 미리보기 실시간 업데이트
