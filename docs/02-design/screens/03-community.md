## 화면 목적
기수별/전체 채널에서 게시글 읽기·쓰기 — 단톡방 대체

## 레이아웃

### Desktop
```
[사이드바] [채널 목록 200px] [게시글 피드] [게시글 상세(선택시)]
           ───────────────   ───────────────
           📢 전체           글쓰기 바
           ─ 17기            PostCard 목록
           ─ 16기            (무한 스크롤)
           ─ 15기
           ...
           ─ 1기
```

### Mobile
```
[채널 선택 탭 (가로 스크롤)]
[글쓰기 플로팅 버튼]
[PostCard 피드]
```

## UI 컴포넌트
- `ChannelList` — 채널 항목 (활성 표시, 읽지 않은 수 배지)
- `PostCard` — 아바타·이름·CohortBadge·시간·본문·이미지·좋아요·댓글수
- `PostDetail` — 전체 본문 + 댓글 목록 + 댓글 입력
- `CommentItem` — 아바타·이름·CohortBadge·댓글 내용·좋아요
- `WriteModal` — 텍스트에디터 + 이미지첨부 + 채널선택 + 게시 버튼
- `PinnedNotice` — 관리자 공지 고정 배너

## 상태 변형
- 빈 채널: "아직 글이 없어요. 첫 글을 작성해보세요"
- 이미지 업로드 중: 프로그레스바
- Realtime 신규 댓글: 댓글 영역 하이라이트

## 인터랙션 노트
- 채널 전환 시 피드 즉시 교체 (Realtime 구독 재연결)
- 게시글 클릭 → 오른쪽 상세 패널 슬라이드 인 (Desktop)
- 게시글 클릭 → 상세 페이지 이동 (Mobile)
- 긴 본문 → "더 보기" 접기/펼치기

## Handoff 체크리스트
- [ ] 채널 목록 + 피드 (Desktop)
- [ ] 채널 탭 + 피드 (Mobile)
- [ ] 게시글 상세 (Desktop 사이드 패널 / Mobile 전체화면)
- [ ] 댓글 목록
- [ ] 게시글 작성 모달
