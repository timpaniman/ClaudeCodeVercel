# Screen: 사용자 프로필

| 항목 | 값 |
|------|----|
| **연결 기능** | F6. 사용자 프로필 |
| **연결 Sprint** | Sprint 6 |
| **PDCA 단계** | Design → Do |
| **상태** | ⬜ 디자인 대기 |

---

## 화면 목적
CEO 프로필 정보 + 활동 포트폴리오 전시

## 레이아웃

### 프로필 보기
```
[프로필 헤더]
  대형 아바타 | 이름 | CohortBadge(기수) | 회사 | 직책
  [프로필 편집 버튼 (본인일 때)]

[탭: 게시글 | 프로젝트 | 임팩트 스토리]
─── 게시글 탭 ───
[PostCard 목록]
─── 프로젝트 탭 ───
[ProjectCard 그리드]
─── 임팩트 스토리 탭 ───
[ImpactCard 목록]
```

### 프로필 편집
```
[아바타 변경 (업로드)]
[이름 / 회사 / 직책 입력]
[자기소개 (textarea, 200자)]
[소셜 링크: GitHub / LinkedIn / 웹사이트]
[저장 버튼]
```

## UI 컴포넌트
- `ProfileHeader` — 대형 아바타(80px)+배경배너+이름+CohortBadge+회사+직책
- `ProfileTabs` — 게시글·프로젝트·임팩트 탭 + 각 수량 표시
- `AvatarUploader` — 원형 크롭 + 업로드

## 상태 변형
- 본인 프로필: 편집 버튼 표시
- 타인 프로필: 편집 버튼 숨김

## Handoff 체크리스트
- [ ] 프로필 보기 (3탭)
- [ ] 프로필 편집 폼
- [ ] 프로필 헤더 (본인/타인)
