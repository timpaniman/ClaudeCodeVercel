## 화면 목적
로그인 후 첫 진입 화면 — 전체 활동 요약 + 빠른 접근

## 레이아웃

### Desktop (3열)
```
[좌측 사이드바 240px]  [메인 피드]  [우측 위젯 280px]
                       ─────────────  ─────────────────
                       글쓰기 입력창  📌 공지사항
                       ─────────────  ─────────────────
                       PostCard 피드  📚 최근 자료 3개
                       (무한 스크롤)  ─────────────────
                                      🤖 AI 빠른 질문
                                      ─────────────────
                                      👥 같은 기수 멤버
```

### Mobile (단열)
```
[상단 헤더: Logo + 알림벨 + 아바타]
[글쓰기 버튼 (플로팅)]
[PostCard 피드 (무한 스크롤)]
[하단 탭바]
```

## UI 컴포넌트
- `Sidebar` — 네비게이션 + 사용자 정보 하단
- `QuickWriteBar` — 아바타 + "무슨 생각을 하고 계세요?" 입력창
- `PostCard` — 아바타·이름·CohortBadge·시간·내용·이미지·액션바
- `NoticePin` — 공지사항 고정 카드 (파란 테두리)
- `ResourceWidget` — 최근 자료 3개 목록
- `AIQuickWidget` — 한 줄 입력 + AI 채팅으로 이동
- `CohortMemberWidget` — 같은 기수 멤버 아바타 5개

## 상태 변형
- 빈 피드 (첫 로그인): "첫 게시글을 작성해보세요" 일러스트
- 로딩: PostCard 스켈레톤 3개

## 인터랙션 노트
- QuickWriteBar 클릭 → 게시글 작성 모달
- PostCard 좋아요 클릭 → 즉각 숫자 업데이트
- Realtime 새 게시글 → 상단 "새 글 N개" 알림 띠
