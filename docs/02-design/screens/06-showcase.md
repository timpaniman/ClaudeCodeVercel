## 화면 목적
CEO들이 만든 AI 프로젝트를 갤러리로 공개 전시 — 포트폴리오 + 동기부여

## 레이아웃

### 갤러리 (Desktop)
```
[카테고리 탭: 전체·챗봇·RAG·자동화·데이터분석]
[기수 필터 드롭다운]  [정렬: 최신순·인기순]
[ProjectCard 3열 그리드]
```

### 갤러리 (Mobile)
```
[카테고리 가로 스크롤 탭]
[ProjectCard 1열 목록]
```

### 프로젝트 상세
```
[스크린샷 캐러셀 (대형)]
[제목 | 작성자 아바타+이름+CohortBadge | 카테고리]
[GitHub 링크 버튼] [데모 링크 버튼]
[프로젝트 설명 (Rich text)]
[태그 목록]
[좋아요 버튼 + 수 | 스크랩 버튼]
[댓글 섹션]
```

### 프로젝트 등록 (멀티스텝)
```
Step 1: 기본 정보 — 제목·설명·카테고리·태그
Step 2: 이미지 — 스크린샷 업로드 (최대 5장)
Step 3: 링크 — GitHub URL·데모 URL
Step 4: 완료 — 미리보기 + 게시 버튼
```

## UI 컴포넌트
- `CategoryTabs` — 카테고리 탭 (활성 탭 primary 배경)
- `ProjectCard` — 썸네일(16:9)·카테고리뱃지·제목·작성자·CohortBadge·좋아요수
- `ImageCarousel` — 스크린샷 슬라이더 + 인디케이터
- `LinkButton` — GitHub / Demo 아이콘 버튼
- `TagList` — 태그 칩 목록
- `MultiStepForm` — 스텝 인디케이터 + 각 단계 폼
- `ImageUploader` — 드래그앤드롭 + 미리보기 그리드

## 상태 변형
- 빈 갤러리: "첫 프로젝트를 등록해보세요" + 등록 CTA
- 이미지 로딩: 블러 플레이스홀더
- 좋아요 클릭: 즉각 숫자 업데이트 + 하트 애니메이션

## 인터랙션 노트
- 카드 호버 시 오버레이(제목+카테고리) 표시
- 이미지 없는 프로젝트 → 카테고리별 기본 썸네일
- 등록 시 각 Step 유효성 검사
