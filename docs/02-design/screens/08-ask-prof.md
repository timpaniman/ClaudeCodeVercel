## 화면 목적
AI가 못 답하는 전문 질문을 교수에게 직접 질문 — 투표로 우선순위 결정

## 레이아웃

### 목록 (Desktop)
```
[상단: "질문하기" 버튼 (우측)]
[필터: 상태 탭 (전체·대기중·검토중·답변완료) | 카테고리 | 정렬]
[QuestionCard 목록 (투표순 기본)]
```

### 질문 상세
```
[QuestionCard 헤더 (제목·카테고리·상태배지·날짜·작성자+CohortBadge)]
[투표 버튼 (+1) + 투표수 (좌측 고정)]
[질문 본문 (전체)]
─────────────────────────────────
[교수 답변 영역]
  [교수 아바타 + "장동인 교수" + 날짜]
  [답변 본문 (Rich text)]
  [지식베이스 등록 완료 배지]
─────────────────────────────────
[댓글 섹션 (회원간 토론)]
```

### 질문 등록
```
[제목 입력]
[카테고리 선택: 코딩·아키텍처·비즈니스·기타]
[내용 입력 (textarea, 최소 50자)]
[AI에게 먼저 물어보기 버튼 → AI Chat 이동]
[질문 등록 버튼]
```

## UI 컴포넌트
- `QuestionCard` — 투표수·제목·카테고리뱃지·StatusBadge·작성자·CohortBadge·댓글수
- `StatusBadge` — 🟡 대기중(yellow) · 🔵 검토중(blue) · ✅ 답변완료(green)
- `VoteButton` — 투표수 크게 + "+1" 버튼 (이미 투표 시 비활성)
- `ProfessorAnswer` — 특별 스타일 답변 영역 (테두리 강조)
- `KnowledgeBaseBadge` — "RAG 지식베이스에 등록됨" 칩
- `CategoryBadge` — 카테고리별 색상 배지

## 상태 변형
- 답변 대기: 회색 빈 답변 영역 "교수님이 검토 중입니다"
- 이미 투표함: 투표 버튼 Primary 색 + 비활성
- 빈 상태: "아직 질문이 없어요" + 첫 질문 CTA

## 인터랙션 노트
- 투표 클릭 → 즉각 숫자 업데이트 + 버튼 상태 변경
- 질문 등록 시 "AI에게 먼저 물어보기" 권유 모달
- 답변 완료 → StatusBadge 자동 업데이트 + 알림 발송

## Handoff 체크리스트
- [ ] 질문 목록 (상태별 필터)
- [ ] 질문 상세 (답변 전/후)
- [ ] 교수 답변 영역 스타일
- [ ] 투표 버튼 상태 (전/후)
- [ ] 질문 등록 폼
