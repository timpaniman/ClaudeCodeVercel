## 화면 목적
운영진 전용 — 사용자 승인/관리, 기수 생성, 통계 확인

## 레이아웃

### Admin 대시보드
```
[KPI 카드 4개: 전체 회원수 | 이번 달 가입 | 오늘 활동 | 미승인 대기]
[차트: 기수별 활성 사용자 (Bar) | 주간 게시글 수 (Line)]
[최근 가입 신청 목록 (빠른 승인 버튼)]
```

### 사용자 관리
```
[검색 + 필터(기수/역할/상태)]
[사용자 테이블: 아바타·이름·이메일·기수·역할·가입일·상태·액션]
[승인 대기 큐 별도 탭]
```

### 기수 관리
```
[기수 목록 테이블: 번호·기간·멤버수·상태·액션]
[기수 생성 버튼 → 모달: 기수번호·시작일·종료일]
```

## UI 컴포넌트
- `KPICard` — 숫자 크게 + 전월 대비 증감 화살표
- `BarChart` / `LineChart` — 기수별/주간 통계
- `UserTable` — 정렬 가능 테이블 + 체크박스 + 일괄 처리
- `ApprovalQueue` — 가입 대기 카드 + 승인/거절 버튼
- `CohortCreateModal` — 기수 생성 폼 모달

## Handoff 체크리스트
- [ ] 대시보드 (KPI + 차트)
- [ ] 사용자 테이블
- [ ] 승인 대기 큐
- [ ] 기수 관리 테이블
