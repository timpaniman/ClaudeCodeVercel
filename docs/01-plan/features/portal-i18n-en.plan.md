# Plan — 포털 영어화(i18n)와 디자인 개선

- 상태: Draft (2026-09-21)
- 관련: `ai4ceo-alumni-portal` v1 (운영 중). 이 문서는 그 위에 얹는 별도 기능이다.

## 1. 목표
1. 포털의 **모든 사용자 화면·메일·정적 파일을 영어로 제공**한다. 영어가 **기본 언어**다.
2. **한국어는 삭제하지 않고 보존**한다(문구를 언어별 파일로 분리). 사용자가 언어를 바꿀 수 있다.
3. 영어화가 끝난 화면을 기준으로 **디자인 일부를 개선**한다. 시안은 Claude Design 으로 만들고 구현으로 이어받는다.

## 2. 결정 사항 (교수님, 2026-09-21)
| 항목 | 결정 |
|------|------|
| 언어 방식 | 영어 기본 + 한국어 보존 (문구 분리) |
| 디자인 | Claude Design 에서 시안을 보며 결정 |
| 순서 | **언어 먼저 → 디자인** (영어 문구 길이가 배치를 바꾸므로 디자인을 두 번 하지 않기 위함) |

## 3. 범위
### 포함
- `src/` 의 화면 문구 약 600줄(81개 파일), 오류·검증 메시지, 날짜·숫자 형식, `<html lang>`
- 알림 메일(Resend) 본문, Supabase 로그인 메일 템플릿 2종(대시보드에 붙여넣기), `manifest.json`·`offline.html`·명단 양식 CSV
- 언어 전환 UI, 자동 테스트(문구를 검사하는 테스트 30개 파일 갱신)
### 제외
- `docs/` 문서(설계서 등)는 한국어 유지
- 콘텐츠(교수님이 올리는 공지·자료 제목·본문)는 번역하지 않는다 — 운영진이 입력한 그대로 표시
- 3개 이상의 언어

## 4. 설계 원칙
- **라이브러리:** `next-intl` 3.26.5 (Next 14 App Router 호환 확인). URL 에 언어 접두사를 붙이지 않는 방식(쿠키 기반) — 기존 주소·메일 링크·PWA `start_url` 이 바뀌지 않는다.
- **언어 결정:** 쿠키 `NEXT_LOCALE`(전환 시 저장, 1년) → 없으면 영어. 브라우저 언어로 자동 판별하지 않는다(영어 기본 요구).
- **문구 파일:** `src/messages/en.json`, `ko.json` (기능별 네임스페이스). 두 파일의 키는 항상 같아야 한다(테스트로 강제).
- **순수 함수(검증·오류 매핑):** 한국어 문장을 돌려주지 않고 **메시지 키**를 돌려주고, 화면이 번역한다. 그래야 서버·클라이언트·테스트 어디서든 언어와 무관하게 검증할 수 있다.
- **누락 방지:** 단위 테스트가 `src/` 에서 한글이 남은 파일을 찾아 "아직 변환하지 않은 파일 목록"과 비교한다. 목록은 작업이 진행되면 줄어들고 끝나면 0 이 된다.
- **메일 언어:** 수신자별 언어가 필요하므로 `profiles.locale`(009 마이그레이션, 기본 `en`)을 추가하고 알림 발송 때 사용한다. 회원이 "내 정보"에서 언어를 바꾸면 쿠키와 함께 저장된다.
- **날짜·숫자:** `Intl` 을 언어에 따라 사용(`en-US`/`ko-KR`). 기수 표기는 영어 "Cohort 17", 한국어 "17기". 이름 정렬은 언어에 맞춘 비교(locale-aware).
- **명단 CSV 열 이름:** 한글·영어 별칭을 모두 계속 인식한다(이미 한글 별칭 지원, 영어 별칭 유지).

## 6. 위험과 대응
| 위험 | 대응 |
|------|------|
| 문구 누락(한국어가 화면에 남음) | 한글 스캔 테스트 + 영어·한국어 키 일치 테스트 |
| 번역 품질(특히 존댓말·호칭) | 영어 원문은 제가 작성하고 교수님이 화면에서 검수. 한국어는 기존 문구를 그대로 옮긴다 |
| 텍스트 길이 변화로 모바일 레이아웃 깨짐 | 단계마다 375px 뷰포트에서 확인 |
| 서버·클라이언트 언어 불일치(하이드레이션 오류) | 언어는 서버가 쿠키로 결정하고 Provider 로 내려준다 |
| 운영 중 사이트에 미완성 번역이 나감 | 단계마다 로컬에서 확인, 운영 배포는 P5 이후. 필요하면 Vercel 미리보기 배포로 검수 |

## 7. 완료 기준
- 영어 기본으로 모든 화면·메일이 영어로 나오고, 한국어로 전환하면 기존 한국어와 동일하다.
- 한글 스캔 테스트 남은 목록 0, 문구 키 일치 테스트 통과, 기존 테스트(단위·RLS·API·스모크) 모두 통과.
- 375px 모바일에서 주요 화면(로그인, 홈, 자료, 공지, 관리자) 배치 이상 없음.
