# 구글 드라이브 → 포털 자료 이전

드라이브에 흩어진 강의 자료를 포털 자료 라이브러리로 옮기는 도구입니다.
**흐름**: 폴더 내려받기 → `migrate:scan`(검수용 표 만들기) → 엑셀로 고치기 → `migrate:import`(미리보기 → 실제 업로드) → 포털에서 검수 후 일괄 공개.
올라간 자료는 **항상 미공개**로 등록되어, 공개하기 전에는 운영진에게만 보입니다.

## 0. 준비
- 운영진 계정으로 한 번 로그인해 `profiles` 에 운영진 프로필이 있어야 합니다 (`--uploader` 로 이 이메일을 씁니다).
- `.env.local` 에 `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` 가 있어야 합니다.

## 1. 드라이브 폴더 내려받기
1. 드라이브 웹에서 이전할 폴더를 우클릭 → **다운로드** (zip으로 내려받아집니다. 용량이 크면 여러 개로 나뉩니다)
2. 압축을 풉니다. 구글 문서·스프레드시트·슬라이드는 자동으로 `.docx` / `.xlsx` / `.pptx` 로 변환되어 내려옵니다.
3. 폴더 구조는 `기수/주차/파일` 이 가장 좋지만 꼭 그렇지 않아도 됩니다 (틀린 추측은 4단계에서 고칩니다).

```
17기/
  8주차/RAG 강의노트.pdf
  8주차/실습코드/rag_demo.py
  과제/1차 과제 안내.pdf
12기/3주차/프롬프트_노트.pdf
공용/오리엔테이션.pdf
```
인식하는 이름: `17기`, `제12기`, `cohort-5`, `8주차`, `3주`, `week 3`, `공용`/`전체`/`common`,
카테고리 힌트(`과제`, `참고자료`, `코드`·`실습`, `강의`). 폴더 이름이 파일 형식보다 우선합니다.

## 2. 스캔해서 검수용 표(manifest.csv) 만들기
```bash
npm run migrate:scan -- --dir "D:\드라이브백업" --out manifest.csv
```
파일은 읽기만 하고 아무것도 올리지 않습니다. 이미 있는 manifest 는 덮어쓰지 않습니다 (`--force` 로만).

## 3. 엑셀로 manifest.csv 열어 고치기
| 열 | 설명 |
|---|---|
| `status` | `ok` = 올림 / `review` = 확인 필요 / `skip` = 올리지 않음 / `done` = 이미 올림(수정하지 마세요) |
| `path` | 내려받은 폴더 기준 파일 경로 |
| `external_url` | 링크로 등록할 때만 (`path` 는 비우기). **영상이나 50MB 초과 파일**은 유튜브·드라이브 링크로 |
| `cohort_number` | 숫자(`17`) 또는 전체 공용이면 `common`. **비워 두면 올라가지 않습니다** (실수로 공용이 되는 것을 막기 위해) |
| `week_number` | 1~20, 없으면 비움 |
| `category` | `lecture`(강의자료) `code`(코드) `video`(영상) `reference`(참고자료) `assignment`(과제) — 한글 이름도 됩니다 |
| `title` | 화면에 보이는 제목 (파일 이름에서 만든 추측값) |
| `tags` | 쉼표로 구분, 최대 10개 |
| `description` | 설명 (선택) |
| `note` | 스캔이 남긴 안내. 자유롭게 지워도 됩니다 |

- `review` 행은 기수를 못 찾은 파일입니다. `cohort_number` 를 채우고 `status` 를 `ok` 로 바꾸세요.
- 올리지 않을 파일은 `status` 를 `skip` 으로 두세요.
- **저장할 때 CSV(UTF-8) 형식을 유지**하세요. (엑셀: 다른 이름으로 저장 → CSV UTF-8)

## 4. 미리보기 (아무것도 올리지 않음)
```bash
npm run migrate:import -- --manifest manifest.csv --dir "D:\드라이브백업" --uploader 운영진이메일
```
`status=ok` 행을 모두 검사해 문제(없는 기수, 잘못된 링크, 없는 파일 등)가 있으면 **한 건도 올리지 않고** 줄 번호와 이유를 알려 줍니다.
문제가 없으면 등록 예정 건수·기수별 개수·용량을 보여 줍니다. `--limit 3` 으로 소량만 먼저 시험해 볼 수 있습니다.

## 5. 실제 업로드
```bash
npm run migrate:import -- --manifest manifest.csv --dir "D:\드라이브백업" --uploader 운영진이메일 --apply
```
- 한 건씩 올리며, 성공할 때마다 manifest 의 `status` 가 `done`, `resource_id` 가 채워집니다.
- **중간에 끊겨도 같은 명령을 다시 실행**하면 이미 올린 것은 건너뛰고 남은 것만 올립니다.
- 실패한 행은 `status=ok` 로 남고 `note` 에 이유가 적힙니다.

## 6. 검수하고 공개하기
1. 포털 `관리자 → 자료`에서 **미공개** 필터로 목록을 확인합니다 (제목·기수·카테고리를 눌러 수정할 수 있습니다).
2. 문제가 없으면 **미공개 자료 전체 선택 → 선택한 N건 공개 (알림 없음)**.
   (이메일 알림은 알림 기능이 준비된 뒤에 켭니다. 대량 공개에서는 항상 알림을 보내지 않습니다.)

## 자주 묻는 질문
- **영상 파일은?** 50MB 제한과 서버 용량 때문에 올리지 않습니다. 유튜브(일부공개)에 올린 뒤 링크로 등록하세요. 포털에서 바로 재생됩니다.
- **같은 파일을 두 번 올렸어요.** `done` 행은 다시 올라가지 않습니다. 이미 올라간 자료는 `관리자 → 자료`에서 삭제하면 저장 파일도 함께 지워집니다.
- **한글 파일 이름은?** 저장 경로는 영문으로 고정되고, 화면에 보이는 이름·다운로드 이름은 `title` 로 만들어지므로 걱정하지 않아도 됩니다.
